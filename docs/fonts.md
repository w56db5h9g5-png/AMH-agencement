# Polices auto-hébergées

Sources : Google Fonts, familles Cormorant Garamond et Manrope. Acquisition via la feuille officielle :

https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;0,500;1,400&family=Manrope:wght@400;500;600&display=swap

Fichiers : `atelier-0` Cormorant italique 400 ; `atelier-1` Cormorant normal 400 ; `atelier-2` Cormorant normal 500 ; `atelier-3`, `atelier-4`, `atelier-5` Manrope normal 400, 500, 600.

Les fichiers TTF fournis par Google ont été convertis en WOFF2 avec FontTools 4.60.1 et Brotli 1.2.1. Sous-ensemble : U+0000–024F, U+1E00–1EFF, U+2000–206F et symboles utilisés dans l’interface. L’ensemble des six fichiers représente environ 137 Ko. Ils sont livrés dans le dépôt et ne nécessitent aucun outil de conversion pour installer ou exécuter le site.
